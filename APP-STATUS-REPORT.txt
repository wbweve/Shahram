1. WHAT THE APP IS
--------------------------------------------------------------------------------
A fully self-contained, bilingual (Danish/English) leadership platform covering
engineering project leadership AND personal/people leadership. It is
click-only by design (every field is a dropdown, picker or chip — no free
text), works offline, and runs with no build step: open index.html in a
browser, or run the Node server (npm start, port 8001) for the audit-backed
API layer.

Two runtime modes:
  - Browser-only: index.html + localStorage, export/import JSON, print any view.
  - Server-backed: server.js (15,830 lines) serves the same app plus a
    hash-chained, fsync'd append-only API (audit, approvals, workspace,
    automation, trust, finance...). Production profile: Docker +
    PostgreSQL (LEADERSHIP_PERSISTENCE=postgres); JSONL locally by default.
